# DroidOS

An intelligent YouTube chat bot management system for streamers, featuring real-time interaction, viewer profiles, and automated stream management.

## Key Features
- **Real-time Interaction**: Fully integrated with YouTube chat to handle commands and user triggers.
- **Viewer Management**: Tracks viewer profiles, points, and activity analytics.
- **Customizable Store**: Allows viewers to redeem rewards like sound effects or GIF triggers.
- **Automated Bot Persona**: Dynamic bot identity that adapts to your stream.
- **Cloud-Powered**: Robust full-stack architecture built with React, Vite, and Firebase.

## Deployment
This application is deployed on Vercel and uses Firebase for backend services.
